## 🤝 Como Colaborar Comigo
Gosto muito de trocar experiências e trabalhar em equipe. Se você quiser colaborar em algum projeto meu:
1. Explore os repositórios públicos no meu perfil.
2. Abra uma **Issue** relatando um problema ou sugerindo uma melhoria.
3. Se quiser colocar a mão na massa, faça um **Fork**, crie sua branch e envie um **Pull Request**.
